These are server-side workers that run outside the request lifecycle. Most are not directly invokable by API clients but are dispatched as side effects of endpoints or scheduled by cron.

## Queue Jobs

Dispatched onto the queue worker. Roughly grouped by domain.

### Core

| Job | Purpose |
|-----|---------|
| `Accomplishment` | Award an accomplishment to a user |
| `AddToWallet` | Credit a wallet transaction (often dispatched by RevenueCat webhook) |
| `EvaluateMedia` | Evaluate uploaded media for quality / moderation |
| `ImportVenueCandidate` | Promote an approved candidate into a real venue |
| `Purge` | Purge Varnish cache by URL and surrogate key |
| `SendEmail` | Generic queued mailable dispatch |
| `SendPushNotification` | Send a push notification to a single user |
| `StoreUserScan` | Persist a user-submitted table scan to S3 |
| `UpdateUserLocation` | Update a user's geolocation in the background |
| `WarmUrl` | Warm a URL into Varnish |

### Email

| `Email\SendReceiptEmail` | Transaction receipt |

### Embeddings

|-----|---------|

## Console Commands

All commands run via `php artisan <signature>`. Grouped by domain.

### AI

| Command | Description |
|---------|-------------|
| `ai:generate` | Generate text via OpenAI / Gemini / Claude |
| `ai:test` | Smoke-test AI service methods |

### Cache

| Command | Description |
|---------|-------------|
| `cache:warm` | Preload Varnish cache with key pages |
| `cache:purge` | Purge Varnish by URL or surrogate key |
| `varnish:cache` | Purge Varnish by key / URL / model class |

### Users
