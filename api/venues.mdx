## List Venues

```bash
GET /v3/venues
GET /v3/venues?lat=40.7128&lon=-74.0060&distance=25
```

## Get Venue

```bash
GET /v3/venues/{venue}
```

## Search Venues

Text-based search.

```bash
GET /v3/venues/search?q=pool+hall
```

## Fuzzy Search (Embeddings)

Vector-based semantic search across venue media and metadata.

```bash
GET /v3/venues/fuzzy-search?q=outdoor%20patio%20with%20billiards
```

## Lookup Venue

Lookup by external identifier (e.g., Google Place ID).

```bash
GET /v3/venues/lookup?place_id=ChIJ...
```

## Random Venue

```bash
GET /v3/venues/random
```

## Duplicates

Public list of detected duplicate venue clusters.

```bash
GET /v3/venues/duplicates
```

## Site Preview

Renderable preview metadata for the venue page.

```bash
GET /v3/venues/{venue}/site-preview
```

## Create Venue

```bash
POST /v3/venues
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "name": "Corner Pocket",
  "address": "123 Main St",
  "latitude": 40.7128,
  "longitude": -74.0060
}
```

## Update Venue

```bash
PUT /v3/venues/{venue}
Authorization: Bearer YOUR_TOKEN
```

## Delete Venue

```bash
DELETE /v3/venues/{venue}
Authorization: Bearer YOUR_TOKEN
```

## Check-ins

### List Check-ins (latest per user)

```bash
GET /v3/venues/{venue}/checkins
```

### Create Check-in

A user can only check in once per hour at a given venue.

```bash
POST /v3/venues/{venue}/checkins
Authorization: Bearer YOUR_TOKEN
```

### Delete Check-in

```bash
DELETE /v3/venues/{venue}/checkins/{checkin}
Authorization: Bearer YOUR_TOKEN
```

### List Media

```bash

```

### Upload Media

```bash
POST /v3/venues/{venue}/media
Authorization: Bearer YOUR_TOKEN
Content-Type: multipart/form-data
```

```bash
POST /v3/venues/{venue}/media/from-url
Authorization: Bearer YOUR_TOKEN
```


```bash
Authorization: Bearer YOUR_TOKEN
```

### Delete Media

## Revisions

User-submitted edits to venue data that go through an approval flow.

### List Revisions

```bash
GET /v3/venues/{venue}/revisions
```

### Create Revision

```bash
POST /v3/venues/{venue}/revisions
Authorization: Bearer YOUR_TOKEN
Content-Type: multipart/form-data
```

**Fields:**
- `data` — revision payload (object)
- `notes` — optional notes (max 1000 chars)
- `image` — optional single image (max 10MB)
- `images[]` — optional array of images (max 10MB each)

### Delete Revision

```bash
DELETE /v3/venues/{venue}/revisions/{revision}
Authorization: Bearer YOUR_TOKEN
```

### Global Revisions Index

```bash
GET /v3/revisions
POST /v3/revisions
```
