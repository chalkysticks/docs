---
title: 'Accomplishments'
description: 'Achievements awarded to users'
---

Accomplishments are achievement records earned by users. Awards happen server-side via the `Accomplishment` job; this API is read-only.

## List Accomplishments

```bash
GET /v3/accomplishments
```

## Get Accomplishment

```bash
GET /v3/accomplishments/{accomplishment}
```

## List For User

```bash
GET /v3/users/{user}/accomplishments
```
