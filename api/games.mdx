---
title: 'Games'
description: 'Individual games, shots, and innings'
---

A game is a single rack/round. For multi-game matches (race to N), see [Matches](/api/matches). Standalone listings of all shots and innings are also documented on [Shots](/api/shots) and [Innings](/api/innings).

## List Games

```bash
GET /v3/games
GET /v3/games?user_id=1
```

## Get Game

```bash
GET /v3/games/{game}
```

**Response:**
```json
{
  "data": {
    "id": 1,
    "game_type": "8ball",
    "user1_id": 1,
    "user2_id": 2,
    "winner_id": null,
    "status": "in_progress",
    "created_at": "2025-01-01T00:00:00Z"
  }
}
```

## Get Game State

Computed game state including current player, ball groups, and score.

```bash
GET /v3/games/{game}/state
```

## Create Game

```bash
POST /v3/games
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "game_type": "8ball",
  "user2_id": 2
}
```

## Update Game

```bash
PUT /v3/games/{game}
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "winner_id": 1,
  "status": "completed"
}
```

## Delete Game

```bash
DELETE /v3/games/{game}
Authorization: Bearer YOUR_TOKEN
```

## Shots (scoped to a game)

### List Shots

```bash
GET /v3/games/{game}/shots
Authorization: Bearer YOUR_TOKEN
```

### Get Shot

```bash
GET /v3/games/{game}/shots/{shot}
Authorization: Bearer YOUR_TOKEN
```

### Record Shot

```bash
POST /v3/games/{game}/shots
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "player_id": 1,
  "ball_pocketed": 3,
  "foul": false
}
```

```bash
PUT /v3/games/{game}/shots/{shot}
Authorization: Bearer YOUR_TOKEN
```

### Delete Shot

```bash
DELETE /v3/games/{game}/shots/{shot}
Authorization: Bearer YOUR_TOKEN
```
