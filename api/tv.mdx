title: 'TV'
description: 'TV channels, live streams, and schedule management'
---

ChalkySticks TV aggregates live and scheduled pool/billiards streams from YouTube, Facebook, and other sources.

## Index

```bash
GET /v3/tv
```

## Channels

### List Channels

```bash
GET /v3/tv/channels
```

### Channel Map

Mapping between channel IDs and metadata.

```bash
GET /v3/tv/channel-map
```

## Live

Currently-live streams.

```bash
GET /v3/tv/live
```

## Schedule

### List Schedule

```bash
GET /v3/tv/schedule
```

### Get Scheduled Item

```bash
GET /v3/tv/schedule/{id}
```

### Create Schedule Entry

```bash
POST /v3/tv/schedule
Authorization: Bearer YOUR_TOKEN
```

### Update Schedule Entry

```bash
PUT /v3/tv/schedule/{tvSchedule}
Authorization: Bearer YOUR_TOKEN
```

### Delete Schedule Entry

```bash
DELETE /v3/tv/schedule/{tvSchedule}
Authorization: Bearer YOUR_TOKEN
```

### Mark Watched

Record that the authenticated user watched a scheduled stream.

```bash
POST /v3/tv/schedule/{tvSchedule}/watch
Authorization: Bearer YOUR_TOKEN
```

## Ingest

Internal ingest endpoint for external schedulers to push channel/stream data. Requires an ingest API key.

```bash
POST /v3/tv/ingest
X-Ingest-Api-Key: YOUR_INGEST_KEY
```
