---
title: 'Diagrams'
description: 'Pool table diagram storage and image generation'
---

Diagrams are addressed by a stable `hash` slug in the URL.

## List Diagrams

```bash
GET /v3/diagrams
```

## Get Diagram

```bash
GET /v3/diagrams/{hash}
```

## Create Diagram

```bash
POST /v3/diagrams
```

**Request:**
```json
{
  "data": { "balls": [...], "lines": [...] },
  "title": "Optional title"
}
```

## Update Diagram

```bash
PUT /v3/diagrams/{diagram}
Authorization: Bearer YOUR_TOKEN
```

## Delete Diagram

```bash
DELETE /v3/diagrams/{diagram}
Authorization: Bearer YOUR_TOKEN
```

## Get SVG Image

```bash
GET /v3/diagrams/{hash}/svg
```

## Get PNG Image

```bash
GET /v3/diagrams/{hash}/png
```

## Generate Images

Force-regenerate the SVG and PNG renderings for a diagram.

```bash
POST /v3/diagrams/{hash}/generate-images
```

## Comments

```bash
GET /v3/diagrams/{hash}/comments
```
