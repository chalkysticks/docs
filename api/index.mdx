## Base URL

```
https://api.chalkysticks.com/v3
```

## Authentication

Most endpoints require authentication via a Sanctum Bearer token:

```bash
curl -H "Authorization: Bearer YOUR_TOKEN" \
     https://api.chalkysticks.com/v3/users/me
```

Tokens are obtained via `POST /v3/auth/login` or `POST /v3/auth/register`. See [Authentication](/api/authentication).

## Response Format

All responses return JSON:

```json
{
  "data": { ... },
  "meta": {
    "pagination": {
      "total": 100,
      "per_page": 15,
      "current_page": 1
    }
  }
}
```

## Error Responses

| Code | Description |
|------|-------------|
| 400 | Bad Request |
| 401 | Unauthorized |
| 403 | Forbidden |
| 404 | Not Found |
| 422 | Validation Error |
| 500 | Server Error |

Error format:

```json
{
  "message": "Error description",
  "errors": {
    "field": ["Validation error message"]
  }
}
```

## Pagination

```bash
GET /v3/venues?page=2&limit=25
```

| Parameter | Default | Max | Description |
|-----------|---------|-----|-------------|
| `page` | 1 | - | Page number |
| `limit` | 15 | 128 | Items per page |

## Caching

Most public read endpoints sit behind Varnish with surrogate-key invalidation. Query parameters and public includes are part of the cache key. Authenticated clients may reuse a public response only when Laravel explicitly guarantees that the representation is identity-independent.

Private account resources use authenticated user-scoped URLs and never enter shared storage. See [API Cache Safety](/infrastructure/api-cache-safety) for the complete contract.

## Rate Limiting

- 60 requests per minute for authenticated users
- 30 requests per minute for unauthenticated
