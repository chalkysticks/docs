---

Content represents long-form items in the feed: articles, videos, embedded YouTube channels, etc. Rulebooks are exposed separately under `/rulebooks`.

## List Content

```bash
GET /v3/content
GET /v3/content?type=video&tags=trickshot&per_page=25
```

Query parameters: `q`/`query`, `all`, `type`, `tags`, `owner_id`, `published`, `sort`, `direction`, `page`, `per_page`.

## Get Content

```bash
GET /v3/content/{content}
```

Public relationships may be embedded without disabling shared caching:

```bash
GET /v3/content/{content}?include=comments,reactions,owner
```

The normalized query string is part of the cache key, so each include set has its own representation.

## Get Channel Detail

Returns enriched channel metadata for content sourced from YouTube.

```bash
GET /v3/content/{content}/detail
```

## Create Content

```bash
POST /v3/content
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "title": "Trick Shot Compilation",
  "media_type": "video",
  "media_url": "https://youtube.com/watch?v=...",
  "thumbnail_url": "https://...",
  "content": "Long description body",
  "published_at": "2026-05-11",
  "tags": [
    { "tag": "trickshot" },
    { "id": 42 }
  ]
}
```

Required: `title`, `media_type`. Optional: `content`, `media_url`, `thumbnail_url`, `published_at`, `created_at`, `tags`.

## Update Content

```bash
PUT /v3/content/{content}
Authorization: Bearer YOUR_TOKEN
```

## Delete Content

```bash
DELETE /v3/content/{content}
Authorization: Bearer YOUR_TOKEN
```

## Comments

```bash
GET /v3/content/{content}/comments
```

Comment mutations purge both the parent content key and the comments-relationship key. A cached article that embeds comments and the standalone comments endpoint therefore refresh together.

## Reactions

```bash
GET /v3/content/{content}/reactions
```

Reaction mutations follow the same parent-key invalidation pattern.
