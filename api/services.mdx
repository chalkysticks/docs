Cross-cutting service endpoints. Many of these proxy or transform third-party data (Google, Yelp, Reddit, YouTube) for use in clients.

## Advertisements

```bash
GET /v3/ads
```

## Statistics

```bash
GET /v3/statistics
GET /v3/statistics/{id}
```

## Beacons

Short-lived location broadcasts from players looking for a game.

### List Beacons

```bash
GET /v3/beacons
GET /v3/beacons?lat=40.7128&lon=-74.0060&distance=10
```

### Get Beacon

```bash
GET /v3/beacons/{beacon}
```

### Create Beacon

```bash
POST /v3/beacons
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "latitude": 40.7128,
  "longitude": -74.0060,
  "message": "Looking for a game!"
}
```

### Delete Beacon

```bash
DELETE /v3/beacons/{beacon}
Authorization: Bearer YOUR_TOKEN
```

## Data Lookups

### Geocode

```bash
GET /v3/data/geocode?address=123%20Main%20St
```

The decoded Google payload is returned directly; `results` and `status` are top-level fields:

```json
{
  "results": [
    {
      "geometry": {
        "location": {
          "lat": 40.7127753,
          "lng": -74.0059728
        }
      }
    }
  ],
  "status": "OK"
}
```

Successful lookups are public and cached by the complete normalized query string. Different `address` values cannot collide. SDK clients should read `results` directly rather than parsing a JSON string from an `original` field.

### YouTube Frame

Grab a single frame from a YouTube video.

```bash
POST /v3/data/youtube/frame
```

**Request:**
```json
{
  "url": "https://youtube.com/watch?v=...",
  "timestamp": 12.5
}
```

### Image To Diagram

Convert a photo of a real pool table into a structured diagram.

```bash
POST /v3/data/image-to-diagram
```

### Table Scan

Scan a single frame of a table.

```bash
POST /v3/data/table-scan
```

### Table Scan (Full)

Full multi-frame table analysis.

```bash
POST /v3/data/table-scan-full
```
