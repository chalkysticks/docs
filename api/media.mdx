Upload-related endpoints. Per-owner media (user media, venue media) lives under [Users](/api/users) and [Venues](/api/venues). This page covers cross-cutting media operations.

## Tagged Media

```bash
GET /v3/media/tags
```

## Media By Users

```bash
GET /v3/media/users
GET /v3/users/{user}/media
```

## Media By Venues

```bash
GET /v3/media/venues
GET /v3/venues/{venue}/media
```

## Presigned Uploads

Use these endpoints to obtain signed URLs from S3 / BunnyStream and upload directly from the client.

### Generic Presigned URL

```bash
POST /v3/media/presigned-url
Authorization: Bearer YOUR_TOKEN
```

### Create Image Upload

```bash
POST /v3/media/image/create-upload
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "filename": "photo.jpg",
  "content_type": "image/jpeg"
}
```

### Create Video Upload

```bash
POST /v3/media/video/create-upload
Authorization: Bearer YOUR_TOKEN
```

## Media Shares

Share or transfer ownership of a piece of user media.

### List Shares

```bash
GET /v3/media/{userMedia}/shares
Authorization: Bearer YOUR_TOKEN
```

### Create Share

```bash
POST /v3/media/{userMedia}/shares
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "shared_with_id": 42,
  "type": "share",
  "message": "Check this out"
}
```

`type` is one of `share` or `transfer`.

### Accept Share

```bash
POST /v3/media/{userMedia}/shares/{share}/accept
Authorization: Bearer YOUR_TOKEN
```

### Reject Share

```bash
POST /v3/media/{userMedia}/shares/{share}/reject
Authorization: Bearer YOUR_TOKEN
```

## Media Tags

Tag a piece of user media with a user or venue.

### List Tags

```bash
GET /v3/media/{userMedia}/tags
Authorization: Bearer YOUR_TOKEN
```

### Create Tag

```bash
POST /v3/media/{userMedia}/tags
Authorization: Bearer YOUR_TOKEN
```

**Request:**
```json
{
  "entity_type": "user",
  "entity_id": 42
}
```

`entity_type` is one of `user` or `venue`.

### Delete Tag

```bash
DELETE /v3/media/{userMedia}/tags/{tag}
Authorization: Bearer YOUR_TOKEN
```

## Comments On Media

```bash
GET /v3/media/{media}/comments
```

## Webhooks

### BunnyStream

```bash
POST /v3/webhooks/bunny
```
