## Installation

```bash
npm install @chalkysticks/vue2-pad
```

## Setup

```typescript
import Vue from 'vue';
import ChalkyPad from '@chalkysticks/vue2-pad';

Vue.use(ChalkyPad);
```

## Basic Usage

```html
<ChalkyPad
    ref="pad"
    v-on:change="handleChange"
/>
```

## Features

- **Ball Placement** - Add cue, solid, striped, and ghost balls
- **Coach Lines** - Draw lines between balls
- **Trajectories** - Visualize shot paths
- **Persistence** - Save/load diagrams via SDK
- **Export** - Generate SVG and PNG images
- **Stateless embeds** - Render URL-driven diagrams without saving; see [Stateless Diagram Embeds](/pad/diagram-embedding)

## Architecture

The pad uses a manager-based architecture:

| Manager | Purpose |
|---------|---------|
| TableManager | Main orchestrator |
| BallManager | Ball operations |
| LineManager | Coach lines |
| RailManager | Table boundaries |
| TrajectoryManager | Shot paths |

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tableType` | string | '9foot' | Table size |
| `showGrid` | boolean | false | Show alignment grid |
| `interactive` | boolean | true | Allow user interaction |
| `readOnly` | boolean | false | View-only mode |

## Events

All events are emitted both locally (via `$emit`) and globally on the Event Bus (prefixed with `pad.`). See the [Events Reference](/pad/events) for the complete catalog.

| Event | Payload | Description |
|-------|---------|-------------|
| `change` | `{ tableState }` | Any table mutation (auto-enriched with full state) |
| `ball:add` | `{ x, y, type? }` | Ball added to table |
| `ball:select` | `{ x, y }` | Ball selected |
| `ball:deselect` | `{ x, y }?` | Balls deselected |
| `ball:remove` | — | Active balls removed |
| `line:add` | `{ x, y }` | Line added from active ball |
| `shape:select` | Shape | Shape selected |
| `text:select` | Text | Text selected |
| `table:loading` | — | Diagram import starting |
| `table:loaded` | — | Diagram import complete |

## Accessing Managers

```typescript
const pad = this.$refs.pad;

const tableManager = pad.tableManager;
const ballManager = pad.ballManager;
const lineManager = pad.lineManager;
```
