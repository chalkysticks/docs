## Accessing Table Manager

```typescript
const tableManager = this.$refs.pad.tableManager;
```

## Common Operations

### Clear Table

```typescript
// Remove all balls and lines
tableManager.clearTable();
```

### Export State

```typescript
// Get current state as JSON
const state = tableManager.exportTableState();

console.log(state);
// {
//   balls: [...],
//   lines: [...],
//   version: '1.0'
// }
```

### Import State

```typescript
// Load a previously saved state
tableManager.importTableState(state);
```

## Sub-Managers

Access specialized managers:

```typescript
// Ball operations
const ballManager = tableManager.ballManager;

// Line operations
const lineManager = tableManager.lineManager;

// Rail/boundary operations
const railManager = tableManager.railManager;

// Trajectory visualization
const trajectoryManager = tableManager.trajectoryManager;
```

## Events

The pad uses a dual-channel event system. Every event emitted via `emitPad()` fires both a local Vue component event and a global Event Bus event prefixed with `pad.`.

### Listening via Component Events

```typescript
// Listen on the component ref
this.$refs.pad.$on('change', (payload) => {
    console.log('Table changed:', payload.tableState);
});
```

### Listening via Event Bus

```typescript
import ChalkySticks from '@chalkysticks/sdk';

// Listen globally with the pad. prefix
ChalkySticks.Core.Event.Bus.on('pad.change', (event) => {
    console.log('Table changed:', event.data.tableState);
});

ChalkySticks.Core.Event.Bus.on('pad.ball:add', (event) => {
    console.log('Ball added:', event.data);
});

ChalkySticks.Core.Event.Bus.on('pad.table:loaded', (event) => {
    console.log('Diagram loaded');
});
```

### Triggering Events Programmatically

```typescript
// Trigger events on the component ref
this.$refs.pad.$emit('ball:add', { x: 0.5, y: 0.5, type: 'cue' });
this.$refs.pad.$emit('table:clear');
this.$refs.pad.$emit('history:undo');

// Or dispatch via Event Bus
ChalkySticks.Core.Event.Bus.dispatch('pad.shape:add', {
    x: 0.5,
    y: 0.5,
    type: 'rect',
});
```

See [Events Reference](/pad/events) for the full catalog of available events.

## Table Dimensions

Coordinates are normalized 0-1:

- `(0, 0)` = Top-left corner
- `(1, 1)` = Bottom-right corner
- `(0.5, 0.5)` = Center of table

```typescript
// Get table dimensions
const dimensions = tableManager.getDimensions();
// { width: 1, height: 0.5 } for 9-foot table ratio
```
