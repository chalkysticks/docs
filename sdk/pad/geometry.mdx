---
title: 'Geometry'
description: 'Mathematical utilities for coordinates, distances, intersections, and Bezier curves'
---

The Geometry module provides utility functions for coordinate calculations. All functions are exported **flat** on the `Geometry` namespace — there are no `Geometry.Bezier.*` / `Geometry.Distance.*` sub-namespaces.

```typescript
import { Geometry } from '@chalkysticks/sdk-pad';

Geometry.lineDistance(0, 0, 3, 4);   // 5
```

---

## Bezier Functions

Quadratic Bezier curve utilities for curved paths (massé shots).

### quadraticBezierPoint

Calculate a point on a quadratic Bezier curve at parameter t.

```typescript
const point = Geometry.quadraticBezierPoint(
    x1, y1,  // Start point
    cx, cy,  // Control point
    x2, y2,  // End point
    t        // Parameter (0 to 1)
);
// { x: number, y: number }
```

### quadraticBezierLength

Approximate curve length via numerical integration.

```typescript
const length = Geometry.quadraticBezierLength(
    x1, y1,      // Start point
    cx, cy,      // Control point
    x2, y2,      // End point
    segments     // Optional: number of segments (default 20)
);
```

### generateSvgPath

Generate an SVG path string for a line, with optional Bezier curve.

```typescript
// Straight line
const straightPath = Geometry.generateSvgPath(x1, y1, x2, y2);
// "M 100,200 L 400,200"

// Curved line with control point
const curvedPath = Geometry.generateSvgPath(x1, y1, x2, y2, cx, cy);
// "M 100,200 Q 250,100 400,200"
```

### quadraticBezierTangentAngle

Tangent angle at a point on the curve.

```typescript
const angle = Geometry.quadraticBezierTangentAngle(
    x1, y1,      // Start point
    cx, cy,      // Control point
    x2, y2,      // End point
    t,           // Parameter (0 to 1)
    degrees      // Optional: return degrees (default true)
);
// Compass-style angle: up=0°, right=90°, down=180°, left=270°
```

### quadraticBezierMidpoint

Midpoint of the curve (`t = 0.5`).

```typescript
const midpoint = Geometry.quadraticBezierMidpoint(x1, y1, cx, cy, x2, y2);
// { x: number, y: number }
```

## Distance Functions

### distanceFromPointToLine

Perpendicular distance from a point to a line.

```typescript
const distance = Geometry.distanceFromPointToLine(
    x1, y1,  // Line start
    x2, y2,  // Line end
    pX, pY   // Point
);
```

### lineDistance

Euclidean distance between two points.

```typescript
const distance = Geometry.lineDistance(x1, y1, x2, y2);
```

### magnitude

Vector magnitude.

```typescript
const mag = Geometry.magnitude({ x: 3, y: 4 }); // 5
```

## Intersection Functions

### lineMidpoint

```typescript
const midpoint = Geometry.lineMidpoint(x1, y1, x2, y2);
// { x: number, y: number }
```

### lineIntersectionPoint

Perpendicular projection of a point onto a line.

```typescript
const intersection = Geometry.lineIntersectionPoint(
    x1, y1,  // Line start
    x2, y2,  // Line end
    pX, pY   // Point
);
// { x: number, y: number }
```

### lineAngle

Line angle in degrees (standard `atan2`, not compass-style).

```typescript
const angle = Geometry.lineAngle(x1, y1, x2, y2);
```

## Normalization Functions

Convert between absolute pixel coordinates and normalized 0-1 coordinates.

### normalizeCoordinates

```typescript
const normalized = Geometry.normalizeCoordinates(
    x, y,           // Pixel coordinates
    bounds,         // { x, y, width, height }
    ballDiameter    // Optional: ball size for edge compensation (default 0)
);
// { x: 0-1, y: 0-1 } — clamped
```

### denormalizeCoordinates

```typescript
const pixels = Geometry.denormalizeCoordinates(
    x, y,           // Normalized coordinates (0-1)
    bounds,         // { x, y, width, height }
    ballDiameter    // Optional: ball size for edge compensation (default 0)
);
// { x: pixels, y: pixels }
```

### clampNormalizedCoordinate

```typescript
Geometry.clampNormalizedCoordinate(1.2);   // 1
Geometry.clampNormalizedCoordinate(-0.1);  // 0
```

### isNormalizedCoordinatePair

```typescript
Geometry.isNormalizedCoordinatePair(0.5, 0.5);   // true
Geometry.isNormalizedCoordinatePair(400, 200);   // false
Geometry.isNormalizedCoordinatePair(undefined, 0.5); // false
```

### rotateVectorCCW

90-degree counter-clockwise rotation in **normalized** space (picture-to-table conversion).

```typescript
const rotated = Geometry.rotateVectorCCW(x, y);
// { x: y, y: 1 - x }
```

### compareObjects

Deep object comparison using JSON serialization.

```typescript
const areEqual = Geometry.compareObjects(obj1, obj2);
// boolean
```

## Examples

### Finding Distance to Aim Line

```typescript
import { Geometry } from '@chalkysticks/sdk-pad';

// Line from cue ball to target
const cueX = 100, cueY = 200;
const targetX = 400, targetY = 200;

// Ghost ball position
const ghostX = 300, ghostY = 180;

// Distance from ghost to aim line
const distance = Geometry.distanceFromPointToLine(
    cueX, cueY,
    targetX, targetY,
    ghostX, ghostY
);

console.log(`Ghost is ${distance}px from aim line`);
```

### Converting Coordinates

```typescript
import { Geometry } from '@chalkysticks/sdk-pad';

const bounds = { x: 0, y: 0, width: 800, height: 400 };
const ballSize = 20;

// Normalize pixel coords to 0-1 (ball-size aware)
const normalized = Geometry.normalizeCoordinates(390, 190, bounds, ballSize);
// { x: 0.5, y: 0.5 }

// Denormalize back to pixels
const pixels = Geometry.denormalizeCoordinates(0.5, 0.5, bounds, ballSize);
// { x: 400, y: 200 }
```

## Recent Changes

- **2.0.0** — No geometry changes; exports remain flat on the `Geometry` namespace (older docs showed `Geometry.Bezier.*` sub-namespaces, which never matched the export shape)
- **1.5.x** — `clampNormalizedCoordinate` and `isNormalizedCoordinatePair` added; `normalizeCoordinates` / `denormalizeCoordinates` clamp and take an optional `ballDiameter`
