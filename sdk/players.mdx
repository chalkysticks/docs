`@chalkysticks/sdk-players` is a lightweight package covering the player-identity and beacon (location broadcast) domains.

## Installation

```bash
npm install @chalkysticks/sdk-players
```

Requires `@chalkysticks/sdk-core` as a peer dependency (`^1.61.5`).

## Exports

```typescript
import {
    Collection,   // Player, Beacon
    Core,         // re-export of sdk-core
    Factory,      // Player.model() / .collection(), Beacon.model() / .collection()
    Model,        // Player, Beacon
} from '@chalkysticks/sdk-players';
```

Factories default `baseUrl` to `Core.Constants.API_URL_V1` and accept standard restmc options (`baseUrl`, `endpoint`, `headers`, `params`, ...).

## Player

```typescript
import { Factory } from '@chalkysticks/sdk-players';

// List players
const players = Factory.Player.collection();
players.setQueryParams({ q: 'Matt' });
await players.fetch();

// Single player
const player = Factory.Player.model();
player.set({ id: 123 });
await player.fetch();

player.getName(); // string
```

### Player Fields

| Field | Description |
|-------|-------------|
| `id` | Player ID |
| `name` | Display name (getter: `getName()`) |
| `created_at` | Created timestamp |
| `updated_at` | Updated timestamp |

Endpoint: `player`.

## Beacons

Beacons are short-lived location broadcasts from players looking for a game. Endpoint: `beacons`.

```typescript
import { Factory } from '@chalkysticks/sdk-players';

const beacons = Factory.Beacon.collection();
await beacons.fetch();

// Broadcast a beacon
const beacon = Factory.Beacon.model();
await beacon.save({
    lat: 40.7128,
    lon: -74.006,
});

// Remove it
await beacon.delete();
```

### Proximity Search

`Collection.Beacon` exposes a static `search` for proximity queries (sends `lat`, `lon`, `d` as query params):

```typescript
import { Collection } from '@chalkysticks/sdk-players';

const nearby = await Collection.Beacon.search(40.7128, -74.006, 10); // lat, lon, distance (default 9999)

nearby.each((beacon) => {
    console.log(beacon.getDistance(), beacon.getTimeAgo());
});
```

### Beacon Fields

| Field | Getter | Description |
|-------|--------|-------------|
| `id` | — | Beacon ID |
| `lat` | `getLatitude()` | Latitude |
| `lon` | `getLongitude()` | Longitude |
| `distance` | `getDistance()` | Distance from the search origin |
| `time_ago` | `getTimeAgo()` | Human-readable age |
| `status` | `getStatus()` | Beacon status |
| `keepalive` | `getKeepAlive()` | Keepalive interval |
| `created_at` | — | Created timestamp |
| `updated_at` | — | Updated timestamp |

### Relationships

```typescript
beacon.user; // Core Model.User (hasOne)
```
