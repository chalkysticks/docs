---
title: 'Collections'
description: 'Data collections for fetching and managing lists of models'
---

Collections extend `Collection.Base<T>`, which wraps `restmc`'s Collection with ChalkySticks-specific helpers: request-event broadcasting, auth token wiring, a reactive framework hook, and a default `limit` sourced from `Environment.app.limit` (default 32).

## Basic Usage

```typescript
import { Collection } from '@chalkysticks/sdk-core';

const venues = new Collection.Venue();
await venues.fetch();

venues.each((venue) => {
    console.log(venue.getName());
});
```

Or via the container so the correct `baseUrl` is injected automatically:

```typescript
import { ChalkySticks, Collection } from '@chalkysticks/sdk-core';

const venues = ChalkySticks.resolve(Collection.Venue);
await venues.fetch();
```

## Query Parameters

Filtering goes through `restmc` query params — there is no `setQuery()`:

```typescript
venues.setQueryParams({ lat: 40.7128, lon: -74.006 });
await venues.fetch();

venues.setQueryParam('include', 'hours,media');
venues.unsetQueryParam('include');
```

## Pagination

`limit` and `page` are constructor options (also settable later); page walking comes from `restmc`:

```typescript
const venues = new Collection.Venue({ limit: 25, page: 1 });
await venues.fetch();

if (venues.hasNext()) {
    await venues.fetchNext();       // replace models
    await venues.fetchNext(true);   // append models
}

await venues.nextPage();            // no-op returning null when there is no next page
await venues.previousPage();
```

## Reactive Hooks

`useReactiveHook` is a **static** method registered once per framework — it runs for every subsequently constructed instance (`Model.Base` has the identical hook):

```typescript
import Vue from 'vue';
import { Collection, Model } from '@chalkysticks/sdk-core';

// e.g. Vue 2.7: make every SDK instance observable
Collection.Base.useReactiveHook((instance) => Vue.observable(instance));
Model.Base.useReactiveHook((instance) => Vue.observable(instance));
```

## Collection Methods

From `restmc`:

```typescript
const venue = venues.get(123);          // by id (or cid / model)
const first = venues.first();
const last = venues.last();
const count = venues.length;

const filtered = venues.filter((v) => v.getCity() === 'New York');
const found = venues.findWhere({ slug: 'amsterdam-billiards' });
const names = venues.pluck('name');

venues.each((v) => { /* ... */ });
venues.sort({ key: 'distance' });
```

`Collection.Base` additions:

```typescript
venues.auth();          // chainable: applies token from Provider.Store
venues.shouldFetch();   // true when not loading and nothing fetched yet
venues.getBaseUrl();    // localUrl override > baseUrl
venues.getCreatedAtTimeAgo(id); // timestamp helpers addressed by model id
venues.isDeleted(id);
```

Collections dispatch the same request lifecycle events as models (`request:loading`, `request:loaded`, `request:error`, `request:unauthorized`, ...) both locally and on the global `Event.Bus`.

## Venue Coordinate Fetching

`Collection.Venue.beforeFetch()` rounds `lat`/`lon` query params to ~0.01° (better cache hits) and sorts results by `distance` after parse — pass coordinates and it handles the rest.

## Natural-Language Search

`VenueSearch` (`/v3/venues/fuzzy-search`) and `EmbeddingSearch` (`/v3/media/search`) are AI-embedding searches with a `search()` convenience method:

```typescript
import { Factory } from '@chalkysticks/sdk-core';

const results = Factory.VenueSearch.collection();
await results.search('outdoor patio with billiards', 20);

results.each((venue) => {
    console.log(venue.getName(), venue.getSimilarityPercentage());
});
```

`VenueSearch` returns unique venues ranked by their best-matching image; `EmbeddingSearch` returns the individual matching images.

## Domain Helpers

```typescript
// LibraryMedia — chainable filters
const library = new Collection.LibraryMedia();
await library.images().fetch();       // type=image
await library.documents().fetch();    // type=document

// UserStat — flat lookup map keyed by `${stat_key}|${scope_type}|${scope_id}`
// (global unscoped rows are mirrored under the raw stat_key)
const stats = user.stats;
await stats.fetch();
stats.toScopedMap();                  // e.g. { total_checkins: 42, 'total_checkins|global|': 42 }

// VenueHour — timezone-aware opening hours
venue.hours.setTimezone('America/New_York');
venue.hours.isOpenNow();
venue.hours.getTodayHours();
```
