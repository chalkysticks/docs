Most `Enum.*` values are string literals so they survive serialization across the SDK → API → database boundary unchanged. Three are numeric: `FeedItemType`, `VenueStatus`, and `FeatureState` (ordered thresholds).

## GameType

PascalCase enum identifying a game variant.

```typescript
import { Enum } from '@chalkysticks/sdk-core';

Enum.GameType.EightBall;     // 'EightBall'
Enum.GameType.NineBall;      // 'NineBall'
Enum.GameType.TenBall;       // 'TenBall'
Enum.GameType.PuzzleRack;    // 'PuzzleRack'
Enum.GameType.TrickShots;    // 'TrickShots'
Enum.GameType.Empty;         // '' — sentinel for "no filter"
```

Full set: `ArtisticPool`, `Balkline`, `BankPool`, `Billiards`, `Blackball`, `Carom`, `ChineseEightBall`, `Cutthroat`, `EightBall`, `Empty`, `Killers`, `NineBall`, `OnePocket`, `PuzzleRack`, `Pyramid`, `Rotation`, `Snooker`, `StraightPool`, `TenBall`, `TrickShots`.

> **Breaking change (v1.57.1):** Old hyphenated values (`'8-ball'`, `'9-ball'`) were replaced with PascalCase (`EightBall`, `NineBall`). Callers that hard-coded the legacy strings need to migrate.

The `Empty` sentinel (v1.57.2) lets dropdowns and filter components represent "any" without inventing a synthetic UI state.

## FeatureState

Numeric thresholds consumed by `Service.Feature` for staged rollouts — higher values open a feature to broader audiences.

```typescript
Enum.FeatureState.Disabled;                      // 0
Enum.FeatureState.EnabledForAdmins;              // 20
Enum.FeatureState.EnabledForStaff;               // 30
Enum.FeatureState.EnabledForSpecialUsers;        // 40
Enum.FeatureState.EnabledForPremiumUsers;        // 45
Enum.FeatureState.EnabledForAuthenticatedUsers;  // 50
Enum.FeatureState.Enabled;                       // 100
```

## Accomplishments

```typescript
Enum.AccomplishmentCategory.Gameplay;   // 'gameplay'
Enum.AccomplishmentCategory.Game8Ball;  // 'game_8ball'
Enum.AccomplishmentCategory.Checkin;    // 'checkin'
Enum.AccomplishmentRarity.Rare;         // 'rare'
```

`AccomplishmentCategory` covers checkins, collectibles, community, economy, exploration, per-game categories (`game_8ball`, `game_9ball`, `game_break`, `game_runs`, `game_wins`, …), league, lifetime, media, milestone, photos, social, and tools. `AccomplishmentRarity`: `common`, `uncommon`, `rare`, `epic`, `legendary`.

## Recent Changes

- `1.68.0` — Added `SubscriptionStatus` and `SubscriptionTier`; `FeatureState` gained `EnabledForPremiumUsers` (45).
- `1.61.0` — Added `FeatureState` alongside the `Service.Feature` gating service.
- `1.57.2` — `GameType.Empty` sentinel added.
- `1.57.1` — **Breaking:** `GameType` values converted to PascalCase; added `PuzzleRack` and `TrickShots`.
- `1.56.0` — `Roles.ContentManager` and `Roles.VenueManager` added.
