## Architecture

The SDK is a monorepo of focused packages built on `sdk-core`.

```typescript
import * as Core         from '@chalkysticks/sdk-core';
import * as Pad          from '@chalkysticks/sdk-pad';
import * as Game         from '@chalkysticks/sdk-game';
import * as Physics      from '@chalkysticks/sdk-physics';
import * as Inference    from '@chalkysticks/sdk-inference';
import * as TableScanner from '@chalkysticks/sdk-table-scanner';
import * as Players      from '@chalkysticks/sdk-players';
import * as TV           from '@chalkysticks/sdk-tv';
import * as Auth         from '@chalkysticks/sdk-authentication';
import * as Extras       from '@chalkysticks/sdk-extras';
```

## Installation

```bash
# Install individual packages as needed
npm install @chalkysticks/sdk-core @chalkysticks/sdk-pad
```

Every domain package declares `@chalkysticks/sdk-core` as a peer dependency — install it alongside whichever packages you use.

## Standard Exports

Each package follows the same export shape:

```typescript
export * as Collection from './Collection'
export * as Model      from './Model'
export * as Factory    from './Factory'
export * as Enum       from './Enum'
export * as Utility    from './Utility'
```

Domain-specific namespaces (`Provider`, `Manager`, `Service`, `Geometry`, `Strategy`, etc.) are added where they make sense.

## Configuration

There is no default export — the main class is the named export `ChalkySticks`:

```typescript
import { ChalkySticks } from '@chalkysticks/sdk-core';

ChalkySticks.configure({
    apiUrl: 'https://api.chalkysticks.com/v3',
});
```

See [Core Package](/sdk/core) for all `configure()` options, [Service Container](/sdk/core/container) and [Service Providers](/sdk/core/providers) for the full bootstrap surface, and [Services](/sdk/core/services) for remote config + feature flags.

## Build Outputs

Each package ships:

- **ESM:** `build/esm/index.js` (`main`, `module`, and `exports` all point here)
- **Web bundle:** `build/web/chalkysticks-*.js`

There is no CJS build. `package.json` exposes the root entry only — subpath imports like `@chalkysticks/sdk-core/Provider/Container` are not supported.

## Dependency Graph

```
sdk-core (foundation)
 ├── restmc             HTTP client (Model/Collection/ActiveRecord base)
 ├── dayjs              date/time (replaced luxon in v1.54.0)
 ├── howler             audio playback (Sound module)
 ├── tus-js-client      resumable uploads
 └── peers: @capacitor/* (geolocation, share, speech), @revenuecat/purchases-capacitor

sdk-authentication  → sdk-core (+ Capacitor OAuth2 / Browser peers)
sdk-pad             → sdk-core
sdk-players         → sdk-core
sdk-tv              → sdk-core
sdk-game            → sdk-core + sdk-pad (Diagram relationship on GameChallenge)
sdk-physics         → sdk-core
sdk-extras          → sdk-core (+ ably for realtime)
sdk-inference       → sdk-core + sdk-extras + inferencejs
sdk-table-scanner   → sdk-core (+ onnxruntime-web / @teachablemachine/image peers)
```
