In the gameplay data model, balls are referenced by number within shot payloads and table states. There is no `BallManager` in `sdk-game` — physical ball bodies live in [`@chalkysticks/sdk-physics`](/sdk/physics) and editor-layer balls live in [`@chalkysticks/sdk-pad`](/sdk/pad/balls) (`Manager.Ball`).

## Ball Numbering

| Type | Numbers | Description |
|------|---------|-------------|
| Cue | 0 | White cue ball (`number === 0` in state payloads) |
| Solid | 1–7 | Solid colored balls |
| Eight | 8 | Eight ball |
| Stripe | 9–15 | Striped balls |

Shot payloads reference balls by integer. `GameShot.pocketed_balls` is an array of ball numbers; a `0` in the pocketed set means the cue ball was pocketed (scratch).

## Ball State

Table states are `IGameShotState` payloads (global type from `sdk-game/types`), each carrying an array of `IBallState`:

```typescript
interface IBallState {
    isPocketed: boolean;
    number: number;        // 0 = cue, 1–15 = object balls
    position: IVector2;    // { x, y }
    velocity?: IVector2;
}

interface IGameShotState {
    ballStates: IBallState[];
    cueParams?: ICueParameters | null;   // { aim, english, position, power }
    currentPlayer?: string | null;
    gameType?: Enum.GameType | null;
    playerGroups?: IPlayerGrouping | null;
    turnCount?: number;
}
```

## Reading Pocketed Balls

```typescript
import { Utility } from '@chalkysticks/sdk-game';

// From a shot record
const balls = shot.getPocketedBalls(); // number[]

// By diffing two table states
const pocketed = Utility.ShotStateParser.determinePocketedBalls(
    shot.getTableStateBefore(),
    shot.getTableStateAfter(),
);
```

`determinePocketedBalls()` returns balls that flipped to `isPocketed` between the two states, plus balls that disappeared from the state entirely.
