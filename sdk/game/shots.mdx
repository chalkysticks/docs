Shots are represented by `Model.GameShot` and `Collection.GameShot` (endpoint `/shots`). Shot **physics** (power, english, trajectories) lives in [`@chalkysticks/sdk-physics`](/sdk/physics); this page covers the data-layer concerns.

## Fields

| Field | Type | Notes |
|-------|------|-------|
| `game_id` | number | Parent game |
| `inning_id` | number \| null | Parent inning |
| `player_id` | number | Shooter |
| `shot_number` | number | Sequence within the game |
| `shot_type` | `Enum.ShotType` \| string | Backend may introduce new values |
| `result` | `Enum.ShotResult` \| string | |
| `is_foul` / `is_safety` | boolean | |
| `pocketed_balls` | number[] | Ball numbers; `0` = cue ball |
| `cue_params` | `ICueParameters` | `{ aim, english, position, power }` |
| `table_state_before` / `table_state_after` | `IGameShotState` | Full ball layout snapshots |
| `player_state` | object | Free-form per-player state JSON |
| `shot_time` | string \| null | |

## Recording A Shot

```typescript
import { ChalkySticks } from '@chalkysticks/sdk-core';
import { Enum, Model } from '@chalkysticks/sdk-game';

const shot = ChalkySticks.resolve(Model.GameShot, {
    game_id:        game.id,
    is_foul:        false,
    player_id:      1,
    pocketed_balls: [3],
    result:         Enum.ShotResult.Made,
    shot_type:      Enum.ShotType.Standard,
});

await shot.save();
```

## Listing Shots

```typescript
import { Factory } from '@chalkysticks/sdk-game';

const shots = Factory.GameShot.collection();
shots.setQueryParams({ game_id: game.id });
await shots.fetch();
```

## Reading A Shot

Getters parse JSON columns defensively (string or pre-parsed object):

```typescript
shot.getShotType();         // Enum.ShotType | string (default: Standard)
shot.getResult();           // Enum.ShotResult | string (default: Missed)
shot.getPocketedBalls();    // number[]
shot.getCueParameters();    // ICueParameters | null
shot.getTableStateBefore(); // IGameShotState | null
shot.getTableStateAfter();  // IGameShotState | null
shot.getPlayerState();      // Record<string, any> | null
shot.isFoul();              // boolean
shot.isSafety();            // boolean
```

Relationships: `shot.player` (default include), `shot.game`, `shot.inning`.

## Shot State Parsing

`Utility.ShotStateParser` decodes and diffs state payloads:

```typescript
import { Enum, Utility } from '@chalkysticks/sdk-game';

// Normalize a payload that may be a JSON string or object
const state = Utility.ShotStateParser.parseState(rawPayload); // IGameShotState | null

// Diff two states → newly pocketed ball numbers
const pocketed = Utility.ShotStateParser.determinePocketedBalls(before, after); // number[]

// Best-effort result classification from the state delta
const result = Utility.ShotStateParser.calculateShotResult(before, after, Enum.ShotResult.Missed);
```

`calculateShotResult()` returns `Scratch` when the cue ball (number `0`) was pocketed, `Made` when anything else was, `Safety` when nothing was pocketed and `turnCount` did not change, otherwise the fallback.

`Utility.GameRules` layers rule checks on top:

```typescript
Utility.GameRules.isLegalShot(game.getGameType(), afterState, { beforeState }); // boolean
Utility.GameRules.inferResult(before, after);                                   // Enum.ShotResult
```

## Recent Changes

- `0.4.0` — `GameRules.isLegalShot()` no longer accepts `GameType.Custom` (`Custom` is a `RackStrategy`, not a `GameType`); per-ruleset legality should dispatch on `Game.ruleset`
- `0.3.1` — `player_state` field and `getPlayerState()` added to `GameShot`
