---
title: 'Racking'
description: 'Rack strategies and standard ball layouts'
---

Racking is described by the `Enum.RackStrategy` axis — the **physical layout** of balls at the start of a game, independent of `MatchFormat` (match shape) and `GameType` (game variant). The enum values partially overlap with `GameType` because common layouts share names with their matching game; the distinction matters for racks with no game counterpart (`DrillLine`, `Clear`, `RandomSpread`, `Custom`) and for games that borrow another game's layout (Killers on an `EightBall` rack).

`RackStrategy` mirrors `App\Enums\RackStrategy` in the ChalkySticks API and the trainer enum — values must stay in sync across all three.

## Available Strategies

```typescript
import { Enum } from '@chalkysticks/sdk-game';

Enum.RackStrategy.EightBall;     // standard 15-ball triangle
Enum.RackStrategy.NineBall;      // diamond rack
Enum.RackStrategy.TenBall;       // 10-ball triangle
Enum.RackStrategy.ThreeBall;     // 3-ball triangle
Enum.RackStrategy.OneBall;       // single object ball
Enum.RackStrategy.Rotation;      // rotation (1–15)
Enum.RackStrategy.StraightPool;  // straight pool (14.1)
Enum.RackStrategy.DrillLine;     // balls in a line
Enum.RackStrategy.RandomSpread;  // randomized scatter
Enum.RackStrategy.Clear;         // table cleared
Enum.RackStrategy.Custom;        // caller-supplied layout
```

All values are PascalCase strings (`'EightBall'`, `'DrillLine'`, ...).

## Persisting The Layout

The chosen layout lives on `Model.Game.rack_strategy`:

```typescript
game.getRackStrategy(); // Enum.RackStrategy (default: EightBall)
```

## Rendering A Rack

For the visual layout in the pad editor, use `Manager.Table` from `@chalkysticks/sdk-pad`:

```typescript
import { Manager } from '@chalkysticks/sdk-pad';

const table = new Manager.Table({ height: 400, width: 800, x: 0, y: 0 });

table.rack8Ball(true);   // include cue ball
table.rack9Ball(true);
table.rack10Ball(true);

table.rackBalls(customBallsArray, false); // second arg: normalized coordinates
table.shuffleBalls();
```

See [Pad → Table Manager](/sdk/pad/table-manager) for the full racking API.
