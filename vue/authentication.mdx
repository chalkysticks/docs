---
title: 'Authentication'
description: 'Login, signup, password reset, and OAuth components'
---

All components consume a shared `ChalkySticks.Model.Authentication` instance. They emit standardized `success` / `error` events and dispatch global bus events (`login:request`, `user.menu:open`) so the parent app can react.

## AuthenticationAuthPanel

Composite panel containing login, signup, social login, and forgot-password flows in one component. The default entry point for most apps.

```html
<ChalkyAuthenticationAuthPanel
    :allow-forgot-password="true"
    :allow-signup="true"
    :include-social="true"
    @success="onLoginSuccess"
    @error="onLoginError"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `allowForgotPassword` | boolean | `true` |
| `allowSignup` | boolean | `true` |
| `authModel` | `Model.Authentication` | factory-created |
| `contextualSignup` | boolean | `true` |
| `includeBasic` | boolean | `true` |
| `includeSocial` | boolean | `false` |

Emits: `login`, `signup`, `success`, `error`.

## AuthenticationBasicLogin

Email + password form. Use this directly when you don't need the panel chrome.

```html
<ChalkyAuthenticationBasicLogin
    :auth-model="authModel"
    @success="onSuccess"
    @forgot-password="showForgotPassword"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `allowForgotPassword` | boolean | `true` |
| `authModel` | `Model.Authentication` | — |

Emits: `forgot-password`, `login`, `success`, `error`.

## AuthenticationForgotPassword

Sends the password-reset email and shows a confirmation state.

```html
<ChalkyAuthenticationForgotPassword
    :auth-model="authModel"
    @success="onEmailSent"
    @cancel="closeForm"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `authModel` | `Model.Authentication` | factory-created |

Emits: `success`, `error`, `cancel`.

## AuthenticationResetPassword

Accepts a password reset token (from the email link) and a new password. Validates locally before submitting.

```html
<ChalkyAuthenticationResetPassword
    :token="$route.query.token"
    @success="redirectToLogin"
    @cancel="goHome"
/>
```

| Prop | Type | Required |
|------|------|----------|
| `authModel` | `Model.Authentication` | no |
| `token` | string | **yes** |

Emits: `success`, `error`, `cancel`.

## AuthenticationSocialLogin

OAuth (Google) button(s). Uses `authModel.loginWithGoogle()` under the hood.

```html
<ChalkyAuthenticationSocialLogin
    :auth-model="authModel"
    redirect-to="/dashboard"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `authModel` | `Model.Authentication` | factory-created |
| `redirectTo` | string | current page URL |

## AuthenticationModal

Controller component that displays both the login panel and the user-settings panel as modals. Listens for global `login:request` and `user.menu:open` events, so anywhere in the app you can just dispatch one of those:

```typescript
ChalkySticks.Event.Bus.dispatch('login:request');
```

```html
<ChalkyAuthenticationModal
    :auth-model="authModel"
    :include-social="true"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `authModel` | `Model.Authentication` | factory-created |
| `contextualSignup` | boolean | `true` |
| `includeBasic` | boolean | `true` |
| `includeSocial` | boolean | `false` |

Methods: `showLogin()`, `hideLogin()`, `showSettings()`, `hideSettings()`.

## AuthenticationNavigation

Navigation chip that shows either a "Sign in" button or an avatar depending on auth state. Tapping it dispatches `login:request` or `user.menu:open` on the global bus.

```html
<ChalkyAuthenticationNavigation
    :auth-model="authModel"
    size="xs"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `authModel` | `Model.Authentication` | factory-created |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg'` | `'xs'` |
| `showArrow` | boolean | `false` |
| `useButton` | boolean | `false` |
