## BrandingBadge

ChalkySticks logo mark with theming and size control. Use anywhere you need just the icon (favicon, app tile, loading indicator).

```html
<ChalkyBrandingBadge mode="dark" size="md" />
```

| Prop | Type | Default |
|------|------|---------|
| `mode` | `'deep' \| 'dark' \| 'light'` | `'dark'` |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'` | `'sm'` |

## BrandingStandard

ChalkySticks wordmark (with optional icon). Use in headers and nav.

```html
<ChalkyBrandingStandard mode="light" size="md" :use-icon="true" />
```

| Prop | Type | Default |
|------|------|---------|
| `mode` | `'dark' \| 'light'` | `'dark'` |
| `size` | sizing variants | `'md'` |
| `useIcon` | boolean | `true` |

## BrandingSplash

Animated splash screen used during cold-start of the web-app. Three-part cascade animation; full-screen by default.

```html
<ChalkyBrandingSplash :auto-animate="true" :fullscreen="true" />
```

| Prop | Type | Default |
|------|------|---------|
| `autoAnimate` | boolean | `true` |
| `fullscreen` | boolean | `true` |

Pair with `BrandingStandard` when you want the wordmark to land after the animation.
