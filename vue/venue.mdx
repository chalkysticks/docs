Eleven components live under the `Venue` namespace: cards and previews, list / map views, hours and details, check-ins, and three contextual action buttons.

## VenueCard

Full venue card with gallery, reactions, address, hours, details, check-ins, comments, and action buttons.

```html
<ChalkyVenueCard
    :venue-model="venue"
    :show-checkins="true"
    :show-comments="true"
    :show-hours="true"
    @checkin:success="onCheckin"
    @login:request="showLogin"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `venueModel` | `Model.Venue` | empty Venue |
| `interactiveGallery` | boolean | `true` |
| `maxGalleryImages` | number | — |
| `showCheckins` | boolean | — |
| `showComments` | boolean | — |
| `showHours` | boolean | — |

Slots: `before`, `content:before`, `content:after`, `checkin:action`, `after`.

Emits: `click:gallery`, `checkin:success`, `login:request`.

CSS classes added at runtime: `type-{venueType}`, `is-closed`, `is-open`, `is-nearby`, `has-table-image`.

## VenueCardPreview

Compact card preview — gallery, name, address, distance, favorite. Used in list / horizontal layouts.

```html
<ChalkyVenueCardPreview :venue-model="venue" />
```

| Prop | Type | Default |
|------|------|---------|
| `venueModel` | `Model.Venue` | empty Venue |
| `interactiveGallery` | boolean | `true` |
| `maxGalleryImages` | number | — |

Distance is read from the `location` Vuex module; shows `NEARBY` when within 0.1 miles.

## VenueRow

Horizontal row layout — single thumbnail, name, address, status badge.

```html
<ChalkyVenueRow :venue-model="venue" @click="open(venue)" />
```

Slots: `before`, `venue` (scoped), `actions`, `after`.

## VenueList

Paginated venue list. Switch between `grid`, `horizontal`, and `list` layouts.

```html
<ChalkyVenueList
    :venue-collection="venueCollection"
    view="grid"
    :use-location="true"
    @venue:select="goToVenue"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `venueCollection` | `Collection.Venue` | factory |
| `view` | `'grid' \| 'horizontal' \| 'list'` | `'grid'` |
| `useLocation` | boolean | `false` |
| `includeActions` | boolean | `true` |
| `selectedVenueId` | string \| number | — |
| `maxGalleryImages` | number | — |

Methods: `setPage(page)`, `nextPage()`, `previousPage()`.

## VenueMap

Google Maps embed showing venue markers and (optionally) player beacons.

```html
<ChalkyVenueMap
    :venue-collection="venueCollection"
    :default-zoom="12"
    @venue:select="onSelect"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `venueCollection` | `Collection.Venue` | — |
| `centerLatitude` | number | from user location |
| `centerLongitude` | number | from user location |
| `defaultZoom` | number | `12` |

Emits: `venue:select`, `marker:click`, `zoom:changed`, `bounds:changed`.

Google Maps must be configured (via `configureGoogleMaps()` in `vue2-components/src/Utility/GoogleMaps`) for the map to load.

## VenueHours

Weekly hours table with today's row highlighted.

```html
<ChalkyVenueHours :venue-model="venue" />
```

## VenueFormattedDetails

Icon-rich list of the venue's amenities — table counts, food, league, tournaments, etc.

```html
<ChalkyVenueFormattedDetails :venue-model="venue" />
```

Slots: `before:list`, `before`, `after`, `after:list`.

## VenueCheckins

Check-in summary — shows up to three recent users plus a CTA. Renders a "Be first" prompt when empty.

```html
<ChalkyVenueCheckins
    :venue-model="venue"
    :minimal="false"
    @checkin:success="onCheckin"
    @login:request="showLogin"
/>
```

| Prop | Type | Default |
|------|------|---------|
| `venueModel` | `Model.Venue` | empty Venue |
| `minimal` | boolean | `false` |

Emits: `checkin:success`, `login:request`, `user:select`.

## Action Buttons

All three follow the same prop shape (`size`, `type`, `useIcon`, `venueModel`) and only render when the venue carries the relevant field.

### VenueButtonCall

Opens the system dialer via `tel:` when the venue has a phone number.

```html
<ChalkyVenueButtonCall :venue-model="venue" size="small" type="secondary" />
```

### VenueButtonDirections

Opens Google Maps with the venue's address.

```html
<ChalkyVenueButtonDirections :venue-model="venue" :use-icon="true" />
```

### VenueButtonWebsite

Opens the venue's website in a new tab.

```html
<ChalkyVenueButtonWebsite :venue-model="venue" />
```

| Prop (all three) | Type | Default |
|------|------|---------|
| `size` | `'small' \| 'medium' \| 'large'` | `'small'` |
| `type` | `'primary' \| 'secondary' \| 'tertiary'` | `'secondary'` |
| `useIcon` | boolean | `false` |
| `venueModel` | `Model.Venue` | empty Venue |
