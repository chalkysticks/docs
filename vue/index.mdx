`@chalkysticks/vue2-components` is the shared Vue 2.7 component library used by the website, web-app (Capacitor), and CMS. It depends on `@chalkysticks/sdk` and `@chalkysticks/sass`.

## Installation

```bash
npm install @chalkysticks/vue2-components
```

## Setup

```typescript
// main.ts
import Vue from 'vue';
import ChalkySticks from '@chalkysticks/vue2-components';

Vue.use(ChalkySticks, {
    provide: {
        router: myRouterInstance,   // optional, hooked into Core/Router
    },
});
```

`Vue.use()` does the following:

- Registers every component globally under the `Chalky` prefix
- Imports `@chalkysticks/sass/build/app.css` + the package's own theme
- Registers the `v-pointer` and `v-tooltip` directives
- Installs the `ToastPlugin`
- Disables REST methods on chat models in favor of the Ably service

## Naming Convention

Components register globally with `Chalky` + the barrel export name (`{Section}{Component}`):

```html
<ChalkyAuthenticationAuthPanel />
<ChalkyUserCard :user-model="user" />
<ChalkyVenueList :venue-collection="venues" />
<ChalkyUiToast type="info" message="Saved" />
```

## Individual Imports

For tree-shaken bundles, import components directly:

```typescript
import { VenueCard, UserCard, AuthenticationAuthPanel } from '@chalkysticks/vue2-components';

export default {
    components: { VenueCard, UserCard, AuthenticationAuthPanel },
};
```

Note: imports use the barrel name without the `Chalky` prefix. The prefix is only applied for global registration.

## Technology Stack

- Vue 2.7 (`vue-property-decorator`, class-based components)
- TypeScript with `@chalkysticks/sdk` types
- GSAP for animations
- Video.js + HLS.js for video playback
- Google Maps for the venue map
- Ably for realtime chat
- Roboflow / ONNX Runtime for in-browser ML (table detection)

## ViewBase

Every component extends `Core/Base.ts` (`ViewBase`), which provides:

- `this.$chalky` — SDK access via Vue's prototype
- Access to Vuex store (`authentication`, `location`, `userGuidance`)
- Asset URL resolver
- Lifecycle hooks shared across the library

## Directives

| Directive | Purpose |
|-----------|---------|
| `v-pointer` | Pointer / touch / gesture events (tap, swipe, pinch) |
| `v-tooltip` | Lightweight tooltip on hover / focus |

## Plugin: Toast

```typescript
import { ToastPlugin, ToastTemplates } from '@chalkysticks/vue2-components';

Vue.use(ToastPlugin);

// Anywhere in a component
this.$toast.show({ message: 'Saved', type: 'success' });
this.$toast.show(ToastTemplates.error('Something went wrong'));
```

Render the toast container once near the root:

```html
<ChalkyUiToastGroup position="top-right" direction="down" />
```

## Vuex Store Modules

Installed automatically. Access via `this.$store.state.<module>` or via the typed getters exposed on each component.

| Module | Purpose |
|--------|---------|
| `authentication` | Logged-in user, token, auth state |
| `location` | Geolocation, distance calculations |
| `userGuidance` | Coach-mark dismissal state |

`persist` plugin syncs select state to localStorage.

## Services

| Service | Purpose |
|---------|---------|
| `Service/Ably` | Realtime channel adapter for chat / game |
| `Service/Avatar` | Avatar URL resolution with fallback chain |
| `Manager/Asset` | Asset URL registry (`Asset.createIndex()` is called on install) |
